# Indotek Sukses v2.3.4

Versi siap deploy untuk Vercel dan Supabase.

## Upgrade dari v2.3.3

1. Ekstrak ZIP.
2. Ganti source repository dengan isi folder ini, tetapi pertahankan folder `.git`.
3. Commit dan Push melalui GitHub Desktop.
4. Tunggu Vercel berstatus **Ready**.
5. Logout, login kembali, lalu lakukan hard refresh.

Tidak ada migration SQL baru untuk versi ini.

## Revisi utama

- Popup produk HP tidak keluar viewport.
- Kartu stok HP lebih ringkas dan terbaca.
- Pembatasan cabang diterapkan di server.
- Visual bawaan dapat dihapus.
- Avatar flat portrait pria, wanita, dan berhijab.
