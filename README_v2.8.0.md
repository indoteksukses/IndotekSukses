# Indotek Sukses v2.8.0

Versi v2.8.0 adalah patch antarmuka dan performa untuk instalasi yang telah memakai v2.7.2.

Fokus perubahan:

- mengurangi query berulang dan payload data yang tidak diperlukan;
- menjaga pencarian tetap responsif pada katalog besar;
- membatasi jumlah elemen produk yang dirender sekaligus;
- mempercepat lookup barcode pada POS;
- menghindari reload penuh saat berpindah halaman;
- merapikan tampilan desktop, tablet, dan HP;
- memberikan indikator loading yang konsisten.

Tidak ada migration SQL baru.
